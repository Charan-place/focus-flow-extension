# Screenshot Capture Guide (private notes)

For Product Hunt and the future Chrome Web Store listing. Capture 4 clean shots of the
popup. The store wants **1280×800** (or 640×400); PH is flexible.

## Setup (make it look good)
- Add 3–4 real-sounding tasks (e.g. "Write launch post", "Fix overlay bug", "Reply to
  PR review"). Mark one done so the ✓ state shows.
- Run a focus session a few times first so Stats has real numbers + a streak.
- Use dark theme (default). Clean desktop background behind it.

## The 4 shots (mac: `Cmd+Shift+4`, then Space to grab just the popup window)

1. **Timer + tasks (the hero shot)** — main view, a task locked in ("LOCKED IN ON"),
   timer mid-session showing the ring partly drained. This is your primary listing image.
2. **The celebration** — easiest via the on-page overlay: set Focus to 1 min, let it
   complete, screenshot the confetti + "Focus Session Complete" overlay on a real page.
3. **Stats view** — click ◈. Show pomodoros, focus minutes, streak, and the 7-day bar
   chart with real bars.
4. **Settings view** — click ⚙. Shows the durations, chime/voice toggles, automation —
   signals it's configurable and polished.

## Save them
- Put in `docs/screenshots/` named `01-timer.png`, `02-celebration.png`,
  `03-stats.png`, `04-settings.png`.
- Optionally add a "Screenshots" section to README linking them.

## Quick polish (optional)
- Pad each shot on a soft gradient background (matches the social-preview look) so they
  pop on Product Hunt. Any tool works; even Preview can add a colored canvas.
